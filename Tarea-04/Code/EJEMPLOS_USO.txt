========================================
SISTEMA DE ARCHIVOS SIMPLE - EJEMPLOS DE USO Y PRUEBAS
========================================

Este documento contiene ejemplos detallados de uso del sistema de archivos
y casos de prueba que demuestran todas las funcionalidades implementadas.

========================================
CASO 1: OPERACIONES BÁSICAS
========================================

Descripción: Crear un archivo, escribir datos, leer y eliminar

Comandos:
---------
> CREATE archivo1.txt 1000
> WRITE archivo1.txt 0 "Hola, mundo"
> READ archivo1.txt 0 11
> LIST
> DELETE archivo1.txt
> LIST

Salida Esperada:
----------------
Archivo 'archivo1.txt' creado exitosamente (1000 bytes)
Datos escritos exitosamente en 'archivo1.txt'
Salida: "Hola, mundo"
Archivos en el sistema:
Nombre                         Tamaño
----------------------------------------
archivo1.txt                     1000 bytes
Archivo 'archivo1.txt' eliminado exitosamente
(no hay archivos)

========================================
NOTAS SOBRE LAS PRUEBAS
========================================

1. Todos los comandos deben ejecutarse en el orden mostrado
2. La salida puede variar ligeramente en formato, pero el contenido debe coincidir
3. Los errores son esperados y demuestran el manejo robusto del sistema
4. Para ejecutar las pruebas automáticas: make test
5. Para pruebas manuales: make run

========================================
VERIFICACIÓN DE FUNCIONALIDAD
========================================

✓ CREATE: Crea archivos con nombre y tamaño especificados
✓ WRITE: Escribe datos en posiciones específicas
✓ READ: Lee datos desde cualquier posición
✓ DELETE: Elimina archivos y libera espacio
✓ LIST: Muestra todos los archivos con sus tamaños
✓ Manejo de errores: Valida todas las operaciones
✓ Gestión de bloques: Asigna y libera bloques correctamente
✓ Múltiples archivos: Soporta operaciones concurrentes
